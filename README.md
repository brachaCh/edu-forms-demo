# מערכת טפסים — הדגמה

הדגמה של מערכת לניהול טפסים ותלמידים בגני ילדים, בתי ספר ותיכונים.
המסכים והשימוש זהים לסביבת ההדגמה: נתונים פיקטיביים בדפדפן, בלי מסד נתונים.

**כל הזכויות שמורות ל-Ofisense ול-Business Room.**

ההדגמה מיועדת לתיק עבודות בלבד.

- אין בה שמות, טלפונים או פרטים מזהים של לקוחות.
- אין בה מידע סודי או רגיש.
- אין מפתחות, אין שליחת דוא״ל ואין סליקת תשלום.

## הפעלה

```bash
npm install
npm run dev
```

ואז לפתוח את `http://localhost:3000`.

במסך הפתיחה בוחרים **כניסה חופשית** ומזינים כל כתובת מייל לדוגמה, למשל `demo@example.com`.
לא נשלח מייל. נפתח אזור אישי עם תלמידים ומורים מומצאים.

## מה כלול

- מסך פתיחה, כניסה חופשית, דשבורד ואזור אישי
- גני ילדים, בתי ספר ותיכונים
- כרטיסי תלמידים, תיקיות וטפסים למילוי על המסך
- נתונים פיקטיביים שנשמרים ב-localStorage של הדפדפן

## מה לא כלול

- מפתחות API או חיבור למסד נתונים
- שליחת דוא״ל
- תשלום
